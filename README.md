# GIS - Gestão de Rotas de Frota

Sistema GIS para visualização, planejamento e gestão de rotas rodoviárias.

## Objetivo

Mapear as rotas da frota a partir de Assis, São Paulo, conectando os municípios atendidos pela operação.

## Cidades atendidas

- Assis (base principal)
- Santa Cruz do Rio Pardo
- Ourinhos
- Botucatu
- Bauru
- Marília
- Lençóis Paulista
- Lins
- Londrina
- Cornélio Procópio
- Avaré
- Itu
- Maringá
- Indaiatuba
- Ponta Grossa
- Uberaba
- Curitiba

## Tecnologias planejadas

- QGIS
- OpenStreetMap
- PostgreSQL e PostGIS
- Java e Spring Boot
- React e TypeScript
- Docker Compose

## Versões planejadas

### v1.0 - Mapa GIS
- Criar o mapa no QGIS.
- Cadastrar a base de saída em Assis.
- Mapear os municípios de destino.
- Preparar as rotas rodoviárias.

### v2.0 - Banco de dados geográfico
- Integrar PostgreSQL e PostGIS.

### v3.0 - Plataforma web
- Desenvolver a interface web e a API.
